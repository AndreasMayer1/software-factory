## 2. Implementation Deviations from Plan

### scripts/__init__.py and scripts/util/__init__.py (unplanned)

The plan did not explicitly mention creating `__init__.py` files. However, the test file imports `from scripts.util.yaml_frontmatter import ...` which requires both `scripts/` and `scripts/util/` to be Python packages. The `scripts/tests/` directory already had an `__init__.py`; the other two were missing. Created both empty files.

### goal_preview.py: Added `Output:` contract to docstring (G5 compatibility)

The plan said to add `# tier: C` to `goal_preview.py`. During the G5 smoke run, `goal_preview.py` would fail G5 (CLI with print() but no `Output:` marker). Added `Output:` to the docstring to make the POC tier-C module compliant with G5. This is correct behavior — a TIER C CLI module must still document its output contract.

### ruff fixes during smoke

Two ruff violations in new files were fixed before smoke completion:
- Removed `# noqa` text from a prose comment in `check_no_handrolled_yaml.py` (ruff parsed the comment text as a malformed directive)
- Flattened two nested `if` → `SIM102` violations in `check_no_handrolled_yaml.py`
- Removed unused `import fcntl` from test file
- Changed nested `with` to single-line in test (SIM117)
- Changed `from typing import Iterator` to `from collections.abc import Iterator` (UP035)

### Tier-discovery scanner NOT implemented (deferred to TASK-PROC-051-04)

Plan §C specified "a tiny helper inside the gate-runner parses the first 20 lines of each `scripts/**/*.py` looking for `# tier: <X>`. Files without the annotation default to TIER B + emit a WARNING." This scanner was NOT implemented in this task. The `MISSING_TIER_SEVERITY = "warning"` constant exists in `check_no_handrolled_yaml.py` as a flip-point but has no consumer yet. Rationale for deferral: with only 3 POC modules annotated, a scanner that emits 60 warnings adds noise without enforcement value. TASK-PROC-051-04 will: (a) annotate all `scripts/` modules, (b) add the discovery scanner (likely `scripts/quality/check_tier_annotations.py`), (c) wire `MISSING_TIER_SEVERITY` consumption and flip it to `"error"`. The convention itself (the `# tier: X` header form after the docstring) IS established in this task on the 3 POC modules and documented in the plan.

### Helper module tier-header form fixed post-handoff

`scripts/util/yaml_frontmatter.py` initially had `Tier: B` inside the docstring instead of the `# tier: B` comment form used by the other two POC modules. Fixed during sanity check: added the canonical comment immediately after the docstring's closing `"""`.

### .gitignore was already updated

The `.gitignore` entry for `.venv/` was already present when checked — a previous session had added it. No duplicate added.
