## Environmental notes for future runs

- The first run on a fresh devcontainer triggers NDK 28.2.13676358 side-by-side
  install (~1.5 GB download, ~5 min). Re-runs reuse the cached NDK.
- The Android SDK ownership change (`chown -R vscode:vscode
  /opt/android-sdk-linux`) is needed once per devcontainer for the install to
  proceed.
- The script does not currently route through `win-command-bridge`. If the
  toolchain ever moves to a Windows-only host, add a
  `flutter_build_bundle_size` entry to `win_bridge_watcher.ps1`'s whitelist and
  invoke this script with `--skip-build` against the resulting build/ contents.
