## Classification rubric (applied per rule)

- **(a) Gate-scriptable** — compliance decidable from syntactic / structural
  property. Propose: lint rule name (flutter_lints / `dart_code_linter`) OR
  regex/grep script under `scripts/quality/`. Note effort S/M/L.
- **(b) Judgment-only** — compliance requires reading intent. Confirm stays in
  `doc/`. If `quality-checker` (reading flow) likely won't catch it, flag as gap.
- **(c) Already gate-enforced** — restated in `doc/` but in current gate set.
  Recommend: keep prose / replace with pointer to gate / both.
