## Script Design

### lookup_analytics.py

Two report modes (selectable via `--gaps` flag):

**Default (analytics report):**
- Lookup count per chain class (`chain` field: code-simple, code-complex, code-bugfix-*, etc.)
- Fallback-to-WebSearch rate = records with `decision: fallback_websearch` / total `looked_up` records
- Cycle × lookup correlation: average lookup count per cycle number across all tasks

**Gap report (--gaps):**
- Filter records where `decision == "fallback_websearch"`
- Group by `technology` field
- Sort by frequency (most-needed coverage first)
- Show example `api_surface` entries per technology

### CLI

```
python3 scripts/lookup_analytics/lookup_analytics.py [OPTIONS]

Options:
  --gaps          Show fallback gap report instead of analytics
  --path PATH     Root to search for lookup_log.jsonl (default: requirements_tasks/)
  --json          Output as JSON (machine-readable)
```
