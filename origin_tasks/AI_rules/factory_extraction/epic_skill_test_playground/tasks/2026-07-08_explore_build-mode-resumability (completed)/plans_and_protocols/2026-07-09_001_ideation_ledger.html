Deployed run = resumable outer task, durable-handle-keyed, harvest gated on explicit completion (preserve-by-default)

Recipe (15 ideas)
  • IDEA-01 Durable runs dir, not mkdtemp — Move isolated_dir out of /tmp into .factory/playground/runs/<handle>/copy so the copy survives reboot & /tmp eviction
  • IDEA-02 Preserve-copy-on-pause — Preserve the whole isolated copy on pause, keyed by a run handle; discard only on verified completion
  • IDEA-07 Run registry file — Host-side run registry JSON (.factory/playground/runs/registry.json): handle -> {copy_path, child_uuid, jsonl_dir, status, baseline_ref}
  • IDEA-08 Named deterministic handle — Run handle is a DETERMINISTIC id (not anonymous uuid4) a cold session can name; registry stores child session UUID for JSONL watch
  • IDEA-09 Deployed run = outer in_progress task — Model the deployed run as an ordinary resumable in_progress TASK in the outer tree; reuse orchestrator find_resumable_in_progress_task; goal.md carries the handle
  • IDEA-10 playground-build-resume skill — A playground-build-resume control skill (mirror layer-derivation-resume) reads the registry and re-attaches with no hand-threaded paths
  • IDEA-12 Gated harvest+discard — Gate harvest+discard on result.succeeded AND reason=='exited' AND explicit completion signal present — never unconditional
  • IDEA-13 Read ChainState complete flag — Trusted completion signal = read the child's ChainState `complete: true` from the copy BEFORE discard
  • IDEA-16 Preserve+skip-harvest on incomplete — On INCOMPLETE: preserve copy + registry status=paused; skip harvest ENTIRELY (zero partial deposit)
  • IDEA-19 Reuse limit-marker detection — Detect limit by reusing classify_session_failure's marker on the child stdout; map to a new LaunchResult.reason=='paused_rate_limit'
  • IDEA-20 Free outer pause via in_progress task — Because the deployed run is an outer in_progress task, the outer orchestrator's EXISTING rate_limited path halts all new dispatch and resumes it — the outer pause is free
  • IDEA-24 reason='paused' first-class — Reframe limit as planned pause not error: LaunchResult.reason gains 'paused' distinct from 'hung'/'session_timeout'
  • IDEA-25 BuildRun protocol — Extract a generic BuildRun protocol (state_location, completion_predicate, resume_fn); derivation is ONE implementation, a skill-test another
  • IDEA-26 Generic build-run resume — Generalize the registry + resume skill to ANY long playground build-mode run (multi-task skill-under-test), not derivation-specific
  • IDEA-27 Injected completion predicate — Completion-predicate injection: derivation passes ChainState-complete; a generic skill-test passes its own done-marker
