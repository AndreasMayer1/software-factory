# Goal: Build VCD Aggregation Script

## Objective

Create a Python script (`scripts/aggregate_value_tradeoffs.py`) that collects all inline Value Trade-off Records from across the project and generates a consolidated summary at `requirements_user_needs/_meta/value_tradeoff_summary.md`.

Also extend `scripts/generate_id_registry.py` to scan for and register VTR-NNN IDs.

## Background

See findings document Q5 for the rationale (replaces standalone "Value Principles" doc), the parseable format specification, and what the output must enable.

## Input Format

The script scans for `<!-- vcd-record` HTML comment blocks embedded in markdown files:

```markdown
<!-- vcd-record
id: VTR-001
date: 2026-03-15
artifact: requirements_user_needs/user_flows/some_flow/flow.md
personas:
  - id: PERSONA-009
    value: Contextual Integrity
    impact: degraded
  - id: PERSONA-010
    value: Simplicity
    impact: supported
decision_status: decided
decided_by: user
-->
```

## Script Behavior

### `scripts/aggregate_value_tradeoffs.py`

1. **Scan directories** (recursively):
   - `requirements_user_needs/`
   - `requirements_tasks/`
   - `doc/presentation/design/`

2. **Parse** each `<!-- vcd-record ... -->` block as YAML

3. **Validate** each record:
   - Required fields present: `id`, `date`, `artifact`, `personas`, `decision_status`
   - ID format: `VTR-NNN`
   - No duplicate IDs

4. **Generate** `requirements_user_needs/_meta/value_tradeoff_summary.md` with:

   ```markdown
   # Value Trade-off Summary

   > Auto-generated by `scripts/aggregate_value_tradeoffs.py`
   > Last updated: [timestamp]
   > Total records: [N] ([N_decided] decided, [N_open] open)

   ## Open Items (requires user decision)

   | ID | Date | Artifact | Personas & Values |
   |---|---|---|---|
   | VTR-XXX | ... | ... | ... |

   ## All Records (chronological)

   | ID | Date | Decision Status | Artifact | Personas | Value Impacts |
   |---|---|---|---|---|---|

   ## Conflict Frequency Matrix

   How often do persona pairs conflict?

   | | PERSONA-009 | PERSONA-010 | PERSONA-002 | ... |
   |---|---|---|---|---|
   | PERSONA-009 | — | 3 | 1 | |
   | PERSONA-010 | 3 | — | 2 | |

   ## Per-Persona Impact Summary

   | Persona | Values Supported | Values Degraded | Net Score |
   |---|---|---|---|
   | PERSONA-009 (Elias) | 2 | 5 | -3 |

   ## Persona Value Reference

   Extracted from persona `vcd:` YAML blocks:

   | Persona | Primary Value | Secondary Values |
   |---|---|---|
   | PERSONA-009 (Elias) | Contextual Integrity | Autonomy, Security, Predictability |
   ```

5. **Exit codes**:
   - `0` — success
   - `1` — validation errors (duplicate IDs, missing required fields)
   - `2` — no records found (warn, don't fail)

### `scripts/generate_id_registry.py` extension

Extend the existing script (do NOT rewrite it) to:
1. Scan for `id: VTR-NNN` patterns in `<!-- vcd-record` blocks
2. Add a "VTR" section to the ID registry output with:
   - Current range
   - Count
   - Next available ID
3. Update the "Next Available IDs" table to include VTR

## Technical Requirements

- Python 3.8+ (consistent with existing scripts)
- No external dependencies beyond stdlib (`re`, `yaml`/`json`, `pathlib`, `datetime`)
- If PyYAML is not available, fall back to regex-based parsing for the YAML blocks
- Script must handle missing `vcd:` blocks gracefully (scan continues)
- Script must work from project root: `python scripts/aggregate_value_tradeoffs.py`

## Output File

`requirements_user_needs/_meta/value_tradeoff_summary.md`

- This file is **read-only** (auto-generated)
- Add a header comment: `> Do NOT edit this file manually. Run: python scripts/aggregate_value_tradeoffs.py`
- Add to `.gitignore` only if the user decides it should not be committed; default: commit it
