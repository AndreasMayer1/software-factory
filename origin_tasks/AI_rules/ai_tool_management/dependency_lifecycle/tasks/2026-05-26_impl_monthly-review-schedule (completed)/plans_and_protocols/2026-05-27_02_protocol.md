### 3. What the routine does

On the 1st of each calendar month:
1. Runs `flutter pub outdated --json` → saves raw JSON to `automation/dependency_reviews/YYYY-MM/flutter_pub_outdated.json`
2. Finds Python manifests under `scripts/`, runs `pip list --outdated` / `uv pip list --outdated` → saves to `automation/dependency_reviews/YYYY-MM/python_outdated.txt`
3. Evaluates each Dart upgrade against REQ-PROC-056 DG1–DG4 (version age ≥ 7 days, no advisories, license OK, download health green)
4. Evaluates each Python upgrade with equivalent checks
5. Writes grouped proposal to `automation/dependency_reviews/YYYY-MM/proposal.md` (4 sections: autonomous bumps / manual review / deferred / security escalations)
6. **Does NOT apply any upgrades** — proposal only
7. Commits the three output files to develop branch
8. Full policy reference: `doc/process/dependency_lifecycle.md`
