# Plan: TASK-PROC-061-02 Monthly Review Schedule

**Date**: 2026-05-27
**Approach**: Inline — use Claude Code `schedule` skill (CronCreate) + documentation

## Chosen Mechanism

**Claude Code cron routine** (`schedule` skill / CronCreate tool)

- Monthly cron: `0 9 1 * *` (1st of each month, 09:00)
- Routine name: `monthly-dep-review`
- Fires without human memory, satisfying AC-01

**Why this over alternatives**:
- Recurring task in backlog: still requires orchestrator to be running on right day; less
  reliable than a cron
- External CI cron: not set up for this project; adds infrastructure complexity
- Claude Code routine: built-in to the project's tooling, self-contained, matches how the
  project's automation already works (orchestrator uses this ecosystem)

## Routine Prompt (what the routine will run)

The routine instructs the agent to:
1. Run `flutter pub outdated` and capture output
2. Run `pip list --outdated` for each manifest under `scripts/`
3. For each candidate: check version age ≥ 7 days (REQ-PROC-056 DG1), check pub.dev
   advisory status (DG2), check license compatibility (DG3), check download health (DG4)
4. Write a grouped proposal to `automation/dependency_reviews/YYYY-MM/proposal.md`
5. NOT apply any upgrades — proposal only
