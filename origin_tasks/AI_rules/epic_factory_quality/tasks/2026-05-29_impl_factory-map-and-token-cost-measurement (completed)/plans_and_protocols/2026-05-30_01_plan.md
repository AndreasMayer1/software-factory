## Design Decisions

### D1: render_factory_map.py

**Input sources:**
- `.claude/skills/*/contract.yaml` — skill nodes + edges (may_invoke, side_effects, derived_from, produces)
- `.claude/schemas/*.yaml` — artifact schema nodes
- `.claude/factory_flows.md` — human-readable flow context (used for family inference)
- `.factory/session_logs/<session>/read_events.jsonl` — heat data (if it exists)

**Node types:**
- `skill` — `.claude/skills/<name>/` (all skills, including those without contract.yaml)
- `artifact` — paths from `produces:` and `derived_from:` fields in contracts
- `schema` — `.claude/schemas/*.yaml` files

**Edge types:**
- `produces` — skill → artifact
- `consumes` — artifact → skill (derived_from)
- `invokes` — skill → skill (may_invoke)
- `script_call` — skill → script (from side_effects paths matching scripts/)
- `schema_ref` — artifact → schema (where schema: field present)

**Family groups** (for filter): `code-*`, `ui-*`, `requ-*`, `task-*`, `claude-*`, `ux-*`, `release-*`, `doc-*`, `verify-*`, `other`

**Output:** `requirements_tasks/STATUS.factory_map.html` — canonical AC-06 single location

**HTML viewer features:**
- Cytoscape.js via CDN (or inlined) with cose layout
- Sidebar with three filter panels: family, artifact-type, distance
- Heat overlay: node color gradient from read-frequency data (grey=no data, blue=low, red=high)
- Legend panel

### D2: aggregate_read_metrics.py

**Input:** `.factory/session_logs/` — JSONL files with `{tool, file_path, session_id, task_id, timestamp, bytes}` records

**Output:** 
- stdout JSON: `{by_file: {path: {reads, bytes_total, sessions}}, by_session: {...}}`
- Emits `.factory/optimize/events/<timestamp>-high-read-file-<hash>.json` for files with reads > threshold (default: 5 reads)

**Event format** (matching existing `.factory/optimize/events/` pattern):
```json
{
  "event_type": "high_read_file",
  "confidence": "medium",
  "fingerprint": "<file_path>@<read_count>",
  "created": "<ISO timestamp>",
  "payload": {
    "file_path": "<path>",
    "read_count": N,
    "total_bytes": N,
    "session_count": N,
    "optimization_candidates": ["cache", "section", "reference"]
  }
}
```

### D3: Read hooks in settings.json

**PreToolUse on Read:**
```json
{
  "matcher": "Read",
  "hooks": [{
    "type": "command",
    "command": "jq -r '.tool_input.file_path // \"\"' | { read -r f; [ -n \"$f\" ] && mkdir -p \".factory/session_logs/${CLAUDE_SESSION_ID}\" && printf '{\"tool\":\"Read\",\"file_path\":\"%s\",\"session_id\":\"%s\",\"task_id\":\"%s\",\"timestamp\":\"%s\"}\\n' \"$f\" \"${CLAUDE_SESSION_ID}\" \"${CLAUDE_TASK_ID:-}\" \"$(date -u +%Y-%m-%dT%H:%M:%SZ)\" >> \".factory/session_logs/${CLAUDE_SESSION_ID}/read_events.jsonl\"; }",
    "statusMessage": "logging read..."
  }]
}
```

**PostToolUse on Read:**
```json
{
  "matcher": "Read",
  "hooks": [{
    "type": "command",
    "command": "BYTES=$(jq -r '.tool_response | length // 0'); FILE=$(jq -r '.tool_input.file_path // \"\"'); [ -n \"$FILE\" ] && [ -n \"$CLAUDE_SESSION_ID\" ] && LAST=\".factory/session_logs/${CLAUDE_SESSION_ID}/read_events.jsonl\" && [ -f \"$LAST\" ] && python3 -c \"import json,sys; lines=open('$LAST').readlines(); last=json.loads(lines[-1]) if lines else {}; last['bytes']=$BYTES; lines[-1]=json.dumps(last)+'\\n'; open('$LAST','w').writelines(lines)\" 2>/dev/null || true",
    "statusMessage": "logging read bytes..."
  }]
}
```
