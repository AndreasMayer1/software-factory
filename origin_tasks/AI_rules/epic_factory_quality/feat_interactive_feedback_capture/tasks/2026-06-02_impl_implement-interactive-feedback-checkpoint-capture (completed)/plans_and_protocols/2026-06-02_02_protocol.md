### Non-obvious fix (doc-update-guidelines candidate)

importlib-loaded module + `@dataclass` + `from __future__ import annotations` → dataclass field
resolution does `sys.modules[cls.__module__].__dict__`, which is None for an unregistered module
(AttributeError). Fix: `sys.modules[spec.name] = module` BEFORE `spec.loader.exec_module(module)`.
This is a recurring gotcha for the `spec_from_file_location` test pattern used across `scripts/tests/`.
