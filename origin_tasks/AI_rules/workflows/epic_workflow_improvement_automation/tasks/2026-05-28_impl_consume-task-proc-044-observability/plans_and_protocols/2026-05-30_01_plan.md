## Changes

### 1. `scripts/factory/aggregate_read_metrics.py` — Pruning + Deduplication

**Pruning (AC-07, per REQ-PROC-044 §6 Developer Guidelines):**
- Add `timedelta` and `shutil` imports
- Add `AGGREGATOR_PRUNE_DAYS = 30` constant
- Add `prune_old_sessions(logs_root: Path, prune_days: int = 30) -> None`:
  - Iterates session dirs under logs_root
  - Parses all JSONL records to find most recent `timestamp` field
  - Removes entire session dir (shutil.rmtree) if most_recent < now - prune_days
  - Retains sessions with no parseable timestamps (fail-safe)
  - Silent no-op when no sessions exceed window
- Update `aggregate_logs(logs_root, prune_days=30)` — call `prune_old_sessions()` before any reads
- Add `--prune-days N` CLI flag (default: 30) to `_build_parser()`
- Pass `args.prune_days` to `aggregate_logs()` in `main()`

**Fingerprint deduplication (AC in goal.md):**
- In `emit_events()`: before the write loop, load existing fingerprints from events_dir
- Skip writing if event's fingerprint already exists in events_dir

**Tests (in `scripts/tests/test_aggregate_read_metrics.py`):**
- `test_prune_removes_old_session` — session dir with timestamp older than 30 days is removed
- `test_prune_retains_recent_session` — session dir with recent timestamp is kept
- `test_prune_retains_session_with_no_timestamps` — fail-safe: no parseable timestamps → retained
- `test_emit_events_skips_duplicate_fingerprint` — event with existing fingerprint not written twice

### 2. `scripts/optimize/run_monitors.py` — Rate-limited aggregator invocation

- Add `import subprocess` to imports
- Add constant `_AGGREGATOR_THRESHOLD = 5`
- Add `_invoke_aggregator() -> None` that calls `aggregate_read_metrics.py --emit-events` via subprocess; guarded by try/except OSError
- In `run_all()`, after the monitors loop:
  - Read state via `mc.load_state()`
  - If `mc.as_int(state.get("completions_since_last_run")) >= _AGGREGATOR_THRESHOLD`, call `_invoke_aggregator()` in a try/except (process boundary guard)
- Update module docstring to reflect aggregator invocation

**Tests (in `scripts/tests/test_run_monitors.py`):**
- `test_aggregator_invoked_when_threshold_met` — verify subprocess.run called when completions >= 5
- `test_aggregator_not_invoked_below_threshold` — verify subprocess.run NOT called when completions < 5

### 3. `scripts/optimize/select_candidate.py` — high_read_file classification

- Add `DIMENSION_TOKEN_COST = "token_cost"` constant
- In `classify()`, add before the catch-all:

  if et == "high_read_file":

- `test_classify_high_read_file_no_cache` — returns ("optimization", "clarity") when cache not in candidates
