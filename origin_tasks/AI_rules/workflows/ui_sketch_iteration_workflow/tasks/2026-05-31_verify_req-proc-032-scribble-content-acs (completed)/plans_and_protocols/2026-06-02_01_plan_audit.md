## Verification standard (read first)

REQ-PROC-032 is a **process requirement**. An AC is satisfied when the **producer
artifact** (skill / agent / schema / script / doc) *specifies* the required behavior
correctly and the **consumers** read it where the AC says they must. A runtime
*instance* of an emitted artifact is NOT required to exist for the AC to pass — except
where the AC names a concrete file that should already exist independent of approval.

**Critical fact**: the only scribble in the repo —
`requirements_tasks/scribbles/therapist/data_transfer/` (v1, v2) — is `status: draft`,
NOT approved. Therefore approval-time / handoff-time runtime artifacts
(`flutter_handoff.yaml`, `APPROVAL_TRAIL.md`, an emitted `flow_navigation.yaml`) are
**legitimately absent** and their absence is NOT a gap. The CONTRACT BLOCK (generation
time, AC-22) and the metadata fields (AC-41) predate-or-postdate this scribble — note
discrepancies as observations, but judge the AC against the *generator/emitter spec*.
