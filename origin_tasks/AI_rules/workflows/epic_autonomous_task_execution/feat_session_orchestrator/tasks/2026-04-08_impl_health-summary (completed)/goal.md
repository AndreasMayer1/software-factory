# Goal: Post-Run Health Summary

## Objective

Add a health summary section to the orchestrator's run report (`automation/reports/*.md`).
Generated by pure Python at the end of every run — no AI session, no token cost.

## What the summary checks

1. **Task progress**: tasks that were `in_progress` at run start → final status at run end
2. **Stuck sessions**: sessions that exited 0 but their task is still `in_progress`
3. **Pending questions**: unanswered `question.md` files in `pending_feedback/`
4. **Overall verdict**: one-line health status (healthy / warnings / blocked)

## Implementation

### In `scripts/automation/orchestrate.py`:

**New function: `snapshot_in_progress_tasks(project_root)`**
- Grep `requirements_tasks/` for `status: in_progress` goal.md files
- Return `dict[task_id → goal_path]` for use at run start and end

**New function: `write_health_summary(report_path, run_data, initial_tasks, feedback_dir, project_root)`**
- Called in `finally` block after `write_report()`
- Appends `## Health Summary` section to the existing report file
- Compares initial in_progress tasks vs current status
- Flags sessions with exit_code 0 but task still in_progress
- Lists unanswered questions

### Data flow

- Snapshot initial in_progress tasks at start of `main()` → store in `run_data["initial_in_progress"]`
- At end (finally): call `write_health_summary()` which appends to the report written by `write_report()`

## Acceptance Criteria

- [ ] Health summary appended to every run report
- [ ] Shows each task that was in_progress at start with its final status (completed ✅ / still in_progress ⚠️)
- [ ] Flags sessions that exited 0 but left task in_progress
- [ ] Lists pending unanswered questions with task IDs
- [ ] Overall verdict line: "Healthy" / "N warning(s)" / "Blocked (N unanswered questions)"
- [ ] Pure Python only — no subprocess claude calls, no LLM
