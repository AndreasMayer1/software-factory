For me it is clear that I want to have a software factory that leads to very good outcomes with the least possible effort.

"good outcomes" is everything from security in dev, security of the app, code maintenance / code quality, speed of the app, UX of the app, good testing, you know what I mean. I think we have other requirements for that, right?

We also have the app provider persona. please check it. I think we might need a requirement. claude.md is not a place for requirements.
